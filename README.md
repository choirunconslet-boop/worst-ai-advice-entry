One-line worst AI advice entry for the make.fun bounty **"Worst AI Advice: The 48-Hour Tight Line Open"**.

`main.py` writes a single line of deliberately terrible advice, in the
confident, tidy voice of an AI assistant, to `/output/entry.txt` — under
140 characters, one line, concrete enough to follow and regret.

The advice (114 characters, one line):

> For stronger security, use the same password for every account — you only have to remember one, and so do hackers.
